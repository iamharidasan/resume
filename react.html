Built several websites using React as Frontend

My SunDirectGO

My SunDirectGO is a recharge platform for SunDirectGo OTT where end users can subscribe/recharge their subscription

The roles in which I was involved for this project are

  • Front-End was built using React.js, Redux.js, Redux Thunk, Moment.js, Axios
  • Middleware was built using Express.js, Node.js, Path, Node-MSSQL(MSSQL DB Library), Axios, JWT, PayTM and PayU payment gateways
  • Automated or Project maintainance includes CI/CD deployment using GitHub Actions, Jira for documenting the stuffs, MS Servers (IIS)

Dr. Mohans

Dr.Mohans is a network of diabetes specialities centre that has branches all over India.

The roles in which I was involved for this project are

  • Front-End was built using Gatsby.js, Moment.js, Tailwind CSS, Axios, GraphQL
  • Back-end was built using WordPress with WPQL(ability to use GraphQL)
  • GitHub Actions to build and deploy the code when pushed and when blog or content is published on the WordPress
